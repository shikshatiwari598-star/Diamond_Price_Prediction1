# 💎 Diamond Price Prediction

A Machine Learning project that predicts diamond prices using Multiple Linear Regression.

## 📌 Project Overview
This project estimates diamond prices based on the diamond's physical measurements.

## 🚀 Features
- Carat
- X (Length)
- Y (Width)
- Z (Depth)
- Predict diamond prices using a trained ML model

## 🛠️ Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Joblib

## 📊 Model Performance
- R² Score: 0.8489

## ▶️ Run Locally
1. Clone this repository.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Run the application:
   `python -m streamlit run app.py`
